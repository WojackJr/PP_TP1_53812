TP1 E1 - Programa de registro de eventos

Sistema de gestion de eventos universitarios

La universidad organiza eventos: jornadas, seminarios, charlas. Necesita un programa que permita cargarlos por consola y ver cuanto sale cada uno.

Escribi el programa completo. No hay codigo previo: arrancas de cero, como en el laboratorio.

La clase EventoUniversitario

Guarda estos datos, todos privados:

Ademas lleva la cuenta de cuantos eventos se crearon en total. Ojo: es un dato de la clase, no de cada objeto — si tenes tres eventos, no hay tres contadores, hay uno solo.

Ese contador se inicializa en un bloque de inicializacion estatico que ademas imprime:

Inicializador estatico: se cargo la clase EventoUniversitario.

Dos constructores:

  1. EventoUniversitario(String id, String titulo, double costoBase, boolean gratuito)

    • El titulo se asigna llamando al setter, no directo. Hay una razon: pensala.

    • Arma un evento nuevo con los mismos datos, salvo el id, que lleva el sufijo -COPIA.

Metodos:

  • getId(), getTitulo()
  • setTitulo(String) — si el titulo es nulo o esta vacio, no hace nada: no lanza excepcion y no cambia el valor anterior.

¡Estás muy cerca! Vamos a aclarar la sintaxis de Java para que quede bien nítido.

Cuando escribís this.id = otro.id;, estás haciendo lo siguiente:

  • this.id: Esto se refiere al atributo id del nuevo objeto que se está creando en este momento a través del constructor de copia. this siempre apunta a la instancia actual (el objeto que se está construyendo o sobre el que se llama un método).
